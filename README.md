# BusinessConnect

BusinessConnect is a group project for CST8326 Web Programming Assignment 2.

This project is a dynamic web application built with Node.js, Express, and Pug. It is based on the assignment requirements in the PDF and is meant to include both public pages and private pages for logged-in users.

## Assignment Requirements

The final project should include:

- user registration and login
- user-based access to private pages
- database functionality to add, display, update, and remove content
- search and filtering
- client-side form validation using JavaScript
- responsive design for desktop and mobile
- template rendering with Pug

## Current Project Pages

The current project includes routes for:

- Home
- Login
- Register
- Dashboard
- Services
- Add Service

## Tech Used

- Node.js
- Express
- Pug
- HTML
- CSS
- JavaScript

## How to Run

Install dependencies:

`npm install`

Start the server:

`npm start`

Open in browser:

`http://localhost:3000`

## Notes

- Main server file: `server.js`
- The final submission should include all required project files and report documents
- `node_modules` should not be included in the final zip submission
